# Sample Defect Reports

## DEF-001

### Title
Renewal Notice Document Not Generated

### Application
Guidewire PolicyCenter

### Severity
High

### Priority
High

### Environment
QA

### Steps To Reproduce

1. Open renewable policy
2. Process renewal
3. Issue renewal transaction
4. Review generated documents

### Actual Result

Renewal notice document is not generated.

### Expected Result

Renewal notice should automatically generate after issuance.

### Status

Resolved
